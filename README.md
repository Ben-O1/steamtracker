# steamtracker
This is a proof-of-concept app that authenticates a user via Steam OpenID and displays basic user data. It will serve as the foundation for a full achievement tracker and comparison platform.

## Features

- Steam login using OpenID
- Basic frontend and backend connection
- User profile info display

---

## Technologies

- Node.js v18
- Express
- React
- Steam Web API
- Passport.js with Steam strategy

---

## How to Run

### Prerequisites

- Node.js v18+
